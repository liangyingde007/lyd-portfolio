# 梁应德个人作品集

Java 后端与 AI 应用开发求职作品集，包含首页、三个项目案例和精简公开简历。

本仓库只保存可公开的网站资产，网站文件位于 `public/`。求职投递用的完整简历和个人资料不在本仓库中。

## Render 发布

- 服务类型：Static Site
- 分支：main
- Build Command：`echo "Static files ready"`
- Publish Directory：`public`

三个可体验项目入口已经在页面中配置：

- 商城：https://lyd-mall.onrender.com
- 导购：https://lyd-shop.onrender.com
- 条例问答：https://lyd-rag.onrender.com

演示的功能范围以各页面说明为准。
